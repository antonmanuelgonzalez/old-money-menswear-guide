# The Heritage Wardrobe

An encrypted static menswear field guide built as a responsive, self-contained HTML page.

## Privacy model

The repository is public, but the guide payload inside `index.html` is encrypted and decrypted in the browser after the visitor supplies the chosen access password.

This is **not equivalent to server-side authentication**. A short password can be guessed or brute-forced offline. The plaintext source is intentionally not committed to this repository.

## Deployment

GitHub Pages serves the repository root from the `main` branch.

## Source note

The guide extracts transferable styling principles from the public Blenin / `@blenin.clothing` Snapchat profile as viewed on 24 July 2026. No affiliation with Blenin.
